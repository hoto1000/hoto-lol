3. How each method counts it

About these methods

  • Plurality (first past the post): each voter's first choice gets one vote. Most votes wins, even without a majority.
  • Ranked-choice (instant runoff): count first choices. If nobody has a majority, drop the last-place candidate and move those ballots to their next choice. Repeat. If candidates tie for last, the first in alphabetical order is dropped.
  • Approval: each voter approves their top two choices in this demo, and the most-approved candidate wins. Real approval ballots let voters approve any number.
  • Head-to-head (Condorcet, with Copeland scoring as a tiebreak when there is a cycle): compare every pair of candidates. A candidate who beats everyone one-on-one wins.

Sources to read further: Instant-runoff voting, Condorcet method, Approval voting. The first example follows the well-known Tennessee capital illustration from the Wikipedia articles, with made-up names. This tool shows how counting rules work. It does not say which rule a place should use.
